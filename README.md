# تقویم شمسی (Kotlin + Jetpack Compose)

## اجرا
1. پوشه پروژه را در Android Studio (نسخه Ladybug یا جدیدتر) باز کنید.
2. صبر کنید Gradle Sync انجام شود (Gradle Wrapper خودکار ساخته می‌شود).
3. روی Run بزنید.

## ویژگی‌ها
- تبدیل دقیق میلادی ↔ شمسی (بدون وابستگی خارجی)، شامل سال‌های کبیسه
- اسکرول بی‌نهایت بین ماه‌ها با افکت چرخش سه‌بعدی
- پس‌زمینه گرادیانی که با فصل تغییر رنگ می‌دهد (بهار، تابستان، پاییز، زمستان)
- ذرات شناور: گلبرگ، جرقه، برگ و برف
- هاله‌ی نبض‌دار روز جاری، انیمیشن فنری روز انتخابی، ظاهر شدن پلکانی خانه‌ها
- کارت شیشه‌ای با نمایش تاریخ میلادی معادل
- راست‌به‌چپ کامل و ارقام فارسی
